

# Aimusic 🎵

A Web application for generating music using **mainstream Large Language Models (LLMs)**. Enter a creative theme, select your preferred AI model, and receive a melody that can be previewed and downloaded as MIDI.

> This project is refactored from an early TensorFlow experimental repository. All legacy code without actual generation logic has been removed.

## Features

- **Multiple Model Options**: OpenAI (GPT-4o), Anthropic Claude, Google Gemini, DeepSeek, Alibaba Qwen, Moonshot Kimi, etc. Models appear in the dropdown once their corresponding API keys are configured.
- **Music Theory Constraints**: Carefully crafted prompts guide models to output structured melodies (key / tempo / time signature / MIDI notes). The backend strictly validates and normalizes the output.
- **Instant Preview**: The frontend synthesizes and plays audio directly using the Web Audio API, requiring no additional audio software.
- **MIDI Download**: Export standard `.mid` files with one click, ready for import into GarageBand, MuseScore, FL Studio, and more for further editing.
- **Visual Piano Roll**: Intuitively view the distribution of generated notes. Scroll horizontally for longer compositions.
- **Generation History**: Results are automatically saved to local history, allowing you to review, replay, or re-export at any time.
- **WeChat Mini Program**: The `miniprogram/` directory provides a complete Mini Program project, supporting cloud sync of history after login (recover across devices).
- **Backend REST API**: The frontend can be replaced by any client, such as a WeChat Mini Program.

## Quick Start

```bash
# 1. Create a virtual environment and install dependencies
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. Configure at least one model's API Key
cp .env.example .env
#    Open .env with an editor and fill in the Key for your chosen model

# 3. Start the server
uvicorn app.main:app --reload
```

Open your browser and visit [http://127.0.0.1:8000](http://127.0.0.1:8000) to get started.

## Model Configuration

Fill in the corresponding API keys for your models in `.env`. **You only need to configure the ones you want**; unconfigured models will not appear in the dropdown:

| Model | Environment Variable | Registration Link |
|-------|----------------------|-------------------|
| OpenAI GPT | `OPENAI_API_KEY` | https://platform.openai.com/api-keys |
| Anthropic Claude | `ANTHROPIC_API_KEY` | https://console.anthropic.com/ |
| Google Gemini | `GEMINI_API_KEY` | https://aistudio.google.com/app/apikey |
| DeepSeek | `DEEPSEEK_API_KEY` | https://platform.deepseek.com/ |
| Alibaba Qwen | `QWEN_API_KEY` | https://dashscope.console.aliyun.com/ |
| Moonshot Kimi | `KIMI_API_KEY` | https://platform.moonshot.cn/ |

You can also specify a specific model version for each one (e.g., `OPENAI_MODEL=gpt-4o-mini`).

## How It Works

```
User inputs theme / style / mood
        │
        ▼
[Build Prompt] ──► [Call Selected LLM] ──► Returns Structured JSON Melody
        │
        ▼
[Parse + Validate + Normalize] (Fault-tolerant JSON extraction, note-name to MIDI conversion, range clamping)
        │
        ▼
[Render] ──► MIDI File (Downloadable) + Notes JSON (Frontend Web Audio playback)
```

## API

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/models` | Returns a list of configured available models |
| `POST` | `/api/generate` | Generates a composition, returns sheet music JSON |
| `GET` | `/api/midi/{filename}` | Downloads the generated MIDI file |
| `POST` | `/api/wx/login` | WeChat login (code to token), used for cloud sync history |
| `GET` | `/api/history` | Current user's history (requires `Authorization: Bearer <token>`) |
| `POST` | `/api/history` | Saves a history record (requires login) |
| `DELETE` | `/api/history/{id}` | Deletes a history record (requires login) |

`POST /api/generate` Request Body Example:

```json
{
  "prompt": "A cheerful Chinese folk song",
  "provider": "deepseek",
  "style": "folk",
  "mood": "cheerful",
  "tempo": 110,
  "duration_bars": 8
}
```

Interactive API documentation is available at [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) (auto-generated by FastAPI).

## WeChat Mini Program

Architecture remains unaffected: the backend is a pure REST API. The Mini Program calls it directly using `wx.request`, with zero changes to the Web frontend logic. Simply create a new Mini Program project.

After starting the backend, import the `miniprogram/` directory using the WeChat DevTools:

1. **Download DevTools**: <https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>. Use **Guest Mode** to preview and get started.
2. **Start Backend**: `uvicorn app.main:app --reload`.
3. **Import Project**: Tools → Import → Select the `miniprogram/` directory.

### BASE_URL Configuration

Guest mode skips domain verification (`urlCheck: false` is already set in `project.config.json`). You only need to adjust the address in `miniprogram/utils/config.js`:

| Scenario | BASE_URL |
|----------|----------|
| DevTools Simulator | `http://127.0.0.1:8000` |
| Real Device Preview (Same LAN) | `http://<PC_LAN_IP>:8000` |
| Production | A registered HTTPS domain, with `request` / `downloadFile` domains configured in the WeChat Official Admin Console |

### Login & Cloud Sync

- **Local History** works out-of-the-box with no configuration needed.
- **Cloud Sync** requires filling in the actual Mini Program `WX_APPID` / `WX_SECRET` in `.env` (obtain from Mini Program Admin Console → Dev Management → Dev Settings). The DevTools can no longer use "Guest Mode"; you must enter your AppID. After successful login, clicking "☁ Sync" on the history page will first upload unsynced local records, then fetch and merge the entire cloud list (cloud items will show a "Cloud" badge).

### Mini Program Directory

```
miniprogram/
├── project.config.json       # Project config (guest appid / skip domain check)
├── app.json                  # Global config + tabBar (Compose / History)
├── utils/
│   ├── config.js             # BASE_URL (change this to switch endpoint)
│   ├── api.js                # wx.request wrapper + token injection + login/history APIs
│   ├── history.js            # Local history storage (wx storage)
│   └── audio.js              # wx.createWebAudioContext player (preview)
└── pages/
    ├── index/                # Compose page: generate + preview + piano roll + export MIDI
    └── history/              # History page: list / play / delete / login & cloud sync
```
